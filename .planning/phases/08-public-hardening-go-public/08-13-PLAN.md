# Plan 08-13: The first visit measured, the proxy's outer wall applied, and what a live connection costs

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 8`): "The site is reachable from the internet over HTTPS through the existing reverse proxy, resilient to traffic floods and unable to starve the other guests on the host, and the owner opens it only after a go-public checklist passes."

Coverage note: D-02's measurement, the proxy half of D-01 and D-06 on the real file (step D of `08-SERVER-STEPS.md`: plan 08-12's approval is general consent to edit the proxy; the edit itself waits for the owner's go on the exact numbers and lines at the checkpoint in Task 2), and D-04's per-connection memory. This plan lifts two prohibitions.

<objective>
Measure one real first visit and what one live connection costs on each transport, and derive the proxy's per-address numbers (D-02, D-04); show the owner the numbers, the backup path and the exact lines, and only after the owner's go apply the outer wall and the HSTS-only headers to the proxy's real dynamic file with a backup and an atomic move (D-01, D-06); prove the LAN route with the route check and its burst. Record numbers only in `08-MEASUREMENTS.md`.

Purpose: the flood in plan 08-15 runs against real, reasoned numbers, and the site-wide live cap can be sized from memory rather than guessed.
Output: `08-MEASUREMENTS.md` (first sections), the real proxy file updated on the proxy container (not in the repository), sanitised evidence in the SUMMARY.
</objective>
