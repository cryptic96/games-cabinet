# Plan 08-06: The proxy's outer wall and the header split in the example files

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 8`): "The site is reachable from the internet over HTTPS through the existing reverse proxy, resilient to traffic floods and unable to starve the other guests on the host, and the owner opens it only after a go-public checklist passes."

Coverage note: this plan lifts SEC-03 adjacency (proxy side) and two prohibitions. The real Traefik file lives only on the proxy container and is edited at execution time in plans 08-13, 08-19 and 08-22; this plan changes the repository's placeholder example and its tests.

<objective>
Update `deploy/traefik/cabinet.yml.example` with the outer wall (D-01, D-02, D-03, D-05): `cabinet-rate-limit` and `cabinet-in-flight` on the public router only, with explicit per-address source criteria; reduce `cabinet-security-headers` to HSTS (D-06); add the `AllowedHosts` placeholder to `deploy/cabinet.env.example`; pin all of it in `deploy/tests/render-templates-test.sh`.

Purpose: the owner can copy a correct outer wall, and the traps (shared buckets, preload, headers sent twice, a rate limit on the owner router) are caught by a test.
Output: the two example files and the render-test assertions.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet to the shared Traefik container | Every request costs Traefik a TLS handshake and routing before any limit |
| Example file to the real proxy configuration | The owner copies the example; a wrong example becomes a wrong proxy |
