- The two SSH aliases are `cabinet-lxc` and `traefik-lxc`; each uses its own maintenance key and a shared master connection. Find each key's path with `ssh -G <alias> | awk '/^identityfile /{print $2}'` and its fingerprint with `ssh-keygen -lf <key>.pub`; keep both only in the session scratchpad.
- `ssh-keygen -y -P '' -f <key>` prints the public key when the private key has no passphrase and fails ("incorrect passphrase") when it has one: a check that needs no passphrase.
- `ssh -O exit <alias>` closes a shared master connection, so a later batch-mode attempt cannot ride an existing connection.
- The maintenance account's authorized keys on each container are read with `sudo` while the agent is still unlocked (before the owner locks it).
</interfaces>

Repository rules: yes or no per check only; never commit to `main`.
