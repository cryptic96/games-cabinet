# Plan 08-03: A scripted route check for the public site, from the home network or from outside

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 8`): "The site is reachable from the internet over HTTPS through the existing reverse proxy, resilient to traffic floods and unable to starve the other guests on the host, and the owner opens it only after a go-public checklist passes."

Coverage note: this plan lifts two prohibitions; it is the scripted half of the external probe (D-11), reused by the LAN-route checks of plans 08-12, 08-13 and 08-19, the go switch in plan 08-22 and later re-checks.

<objective>
Write `build/check-public-routes.sh` and its offline test, modelled on `build/check-owner-routes.sh`: hostnames from the environment, an explicit vantage point (`--from-lan` or `--from-outside`), PASS or FAIL per check with status codes only, and an opt-in `--burst` that proves the app's per-client limit through the real route.

Purpose: the go-public checklist's deterministic items (routes, headers, noindex, credit, burst) become one repeatable command, usable again for every later re-check.
Output: the script and its test, picked up by `build/lint.sh script-tests`.
</objective>

- `build/check-owner-routes.sh` (93 lines): `###` doc header (hostnames from the environment, never written down or printed), `set -euo pipefail`, `pass()` / `fail()` printing `PASS - ...` / `FAIL - ...`, `fetch HOST PATH` with `curl -s --max-time 15 -o "$BODY_FILE" -w '%{http_code}' "https://${host}${path}"` and `STATUS="${STATUS:-000}"`, `expect_status label host path wanted`, `main` returning 2 without hostnames and `[[ "$FAILED" -eq 0 ]]` at the end, `WORK_DIR="$(mktemp -d)"; trap 'rm -rf "$WORK_DIR"' EXIT`.
- `build/tests/check-owner-routes-test.sh` (150 lines): a stub `curl` in `${WORK_DIR}/bin` parsing `-o`, `-w`, `--max-time` and the URL and answering from `STUB_TABLE` (tab-separated URL, status, body; an unknown URL prints `000`); `write_table` with `URL=STATUS=BODY` overrides; `run_check` with a cleaned environment and `PATH="${STUB_BIN}:${PATH}"`; `check description expected actual`; assertions that a healthy table exits 0, each deviation gives one named FAIL, a missing hostname exits 2, and neither hostname appears in the report. Test hostnames `owner.example.com` and `cabinet.example.org`.
- Pages: `Cabinet.Service/Pages/Shared/_Layout.cshtml` has `<meta name="robots" content="noindex" />`; `_Footer.cshtml` has `<a class="bgg-credit" href="https://boardgamegeek.com" rel="noopener">`; `/img/powered-by-bgg.svg` is a static file; the live negotiate route is `POST /cabinet/live/negotiate?negotiateVersion=1`.
- Header values the app will send (plan 08-08): CSP `default-src 'self'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'; object-src 'none'`, `nosniff`, `strict-origin-when-cross-origin`, `DENY`, a Permissions-Policy that switches features off with `()`, COOP `same-origin`, CORP `same-origin`. HSTS comes from Traefik (`max-age=31536000`), without the preload flag.
- `build/lint/checks/50-script-tests.sh` runs every `build/tests/*.sh` and `deploy/tests/*.sh`; `30-shell.sh` shellchecks them.
</interfaces>
