# Plan 08-09: Card dialogs and the back button stop flaking, and the flaky-tests todo is closed

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 8`): "The site is reachable from the internet over HTTPS through the existing reverse proxy, resilient to traffic floods and unable to starve the other guests on the host, and the owner opens it only after a go-public checklist passes."

Coverage note: the second half of the folded todo (card dialogs that did not close in time, `BackButtonTests`, `SheetDragTests`); the first half (live waits, sample-400 first draw) was plan 08-04. This plan closes the todo and lifts one prohibition.

<objective>
Give every card test one shared, condition-based close; replace one-shot address reads with retrying assertions; set a generous default expect timeout once in the browser test base; measure before and after; close the todo.

Purpose: the CI browser suite that gates the release which goes public is trustworthy (D-10 verifies "the full browser suite under the CSP").
Output: the base helper, six hardened classes, the todo moved to `completed/` with the counts.
</objective>

<interfaces>
- `Cabinet.BrowserTests/Infrastructure/CabinetPageTest.cs`: `WaitUntilTheCardStepIsGoneAsync()` (line 88), `GotoCabinetAsync`, `OpenCard` selector usage in derived classes; no default expect timeout is set anywhere (Playwright's default is 5 s). Playwright .NET sets the default for retrying assertions with `SetDefaultExpectTimeout(float)`.
- Private copies of a close helper: `CardContentTests.CloseCardAsync` (line 238), `CardExpansionTests.CloseCardAsync` (line 199), `CardLookScenarios.CloseCardAsync` (protected, line 203; `CardLookTests` and `PhoneCardLookTests` derive from it); each presses Escape, expects `OpenCard` count 0 and waits for the card step. `CardOpenTests` presses Escape inline at lines 39, 63 and 84.
- The opening animation's settled marker: `Expect(Page.Locator("html[data-pull-kind]")).ToHaveCountAsync(0)` (used in `BackButtonTests.OpenCardAfterBlankPageAsync` and `CardSyncTests`).
- One-shot address reads right after going back: `Page.Url.Should().Be(...)` in `BackButtonTests.cs` (lines 27, 31, 43, 47, 58, 62, 73, 77, 109, 114, 132) and `SheetDragTests.cs` (67, 71, 209, 213).
- A method in a derived class with the same name as a base member is a hiding warning, and warnings are errors in this repository: remove every private copy when the base gains `CloseCardAsync`.
- Run each browser class solo (inotify limit), under `systemd-run --user --scope -p CPUQuota=100%` for the counts, and also under the DejaVu fontconfig for classes that measure layout (`SheetDragTests`, `CardLookTests`).
</interfaces>

Repository rules: no planning references in test names, comments or strings; `///` comments only; never commit to `main`. Before any 10-run gate, write the DejaVu fontconfig shown in `docs/development.md` ("keep a font configuration file outside the repository") to the session scratchpad and export `CABINET_DEJAVU_CONF` with its path; the verify refuses to run while another test run of the solution is in progress (`pgrep -x` on the test apps' process names, which cannot match the check's own command line), and the wave placement keeps other plans' builds off the machine (the gate runs alone).
