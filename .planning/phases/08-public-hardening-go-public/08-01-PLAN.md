<objective>

Purpose: accepted risk AR-03-02 (no per-client sync limiter) can be closed, and "a much stricter limit on sync now" (SEC-02) exists in the app.
Output: `Cabinet.Service/Limits/` (settings, partition key, policy, registration), the endpoint wiring, `SyncRateLimitTests`, unit tests, the untrusted-peer host extended, a page-script case.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet client to Traefik to the app's public port | The client address reaches the app only through `X-Forwarded-For`, believed from the known proxy only |
| Visitor press to the sync coordinator | An untrusted, bodyless POST that can start one BoardGameGeek sync per shared window |
