# Plan 08-11: The measurement release, part one - pull request, the owner's merge and tag, and a verified draft

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 8`): "The site is reachable from the internet over HTTPS through the existing reverse proxy, resilient to traffic floods and unable to starve the other guests on the host, and the owner opens it only after a go-public checklist passes."

Coverage note: the established release path of plans 07-46 and 07-47, used here for the pre-release that the measurements run on (research "Release flow for v1.0.0", "Pitfall 5"). The latest published release is `v0.10.0`.

<objective>
Take all the hardening (plans 08-01 to 08-10) to a verified release draft: pull request, checks watched by the orchestrator, the owner's explicit approval to merge and tag with the version, the attested draft verified on the workstation, and the owner told plainly that the draft is verified. Deploying and applying the server-side settings follow in plan 08-12. The public route keeps its LAN/VPN allow-list.

Purpose: the measurements need the new code and templates running on the real container, and releases are immutable, so they run on a `0.x` build.
Output: the merged pull request, the approved tag, a verified draft, sanitised evidence in the SUMMARY.
</objective>
