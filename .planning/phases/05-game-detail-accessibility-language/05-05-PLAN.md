# Plan 05-05: The status line and the scripts speak both languages

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 5`): "A visitor can tap any box, watch it slide out of the shelf, and read everything needed to pick it for game night in English or Dutch, by touch, mouse, keyboard or screen reader."

<objective>
Make the generated sentences follow the language: the relative and exact sync times, the stale notes and every script string (`copy.js` becomes an English and a Dutch table), kept identical between server and script by shared vectors (D-25), plus the script side of the toggle and a browser proof of switching.

Purpose: completes the language requirement end to end; every later script string (the card, the list) is added to both tables from here on.
Output: language-aware `SyncStatusText`, two `copy.js` tables, `language.js`, shared vectors, parity tests, `LanguageSwitchTests`.
</objective>
