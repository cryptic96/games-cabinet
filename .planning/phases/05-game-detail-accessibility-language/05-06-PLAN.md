# Plan 05-06: A tap opens the card, and every way of closing it works

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 5`): "A visitor can tap any box, watch it slide out of the shelf, and read everything needed to pick it for game night in English or Dutch, by touch, mouse, keyboard or screen reader."

<objective>
The first visible slice of the card: tapping any box opens a native modal dialog with that game's cover, title, year and BGG link, from card data already in memory; Escape, ✕, an outside tap and Back each close it exactly once, with focus back on the box and no dead history step (D-03, D-04 static shape, D-05, D-07, D-09). The pull-out animation, the full card content and the sheet drag follow in later plans.

Purpose: the core interaction of DET-01 and the container DET-02's content lives in.
Output: `detail.js`, `card-view.js`, `card-flow.js`, `card.css`, `icons.svg`, the dialog shell, the card strings in both languages, node and browser tests.
</objective>
