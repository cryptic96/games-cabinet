# Plan 05-10: A games list for screen readers, with a skip link

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 5`): "A visitor can tap any box, watch it slide out of the shelf, and read everything needed to pick it for game night in English or Dutch, by touch, mouse, keyboard or screen reader."

<objective>
A screen-reader user gets an A to Z list of every game behind the visual cabinet, each entry announcing the game-night facts and opening the same card; a keyboard user reaches it with a skip link (D-18, D-19, D-20).

Purpose: A11Y-02.
Output: `games-list.js`, the list shell and skip link in the page, panel and skip-link styles, node and browser tests.
</objective>
