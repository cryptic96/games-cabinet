# Plan 05-04: The page in Dutch from the first byte, and the language toggle

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 5`): "A visitor can tap any box, watch it slide out of the shelf, and read everything needed to pick it for game night in English or Dutch, by touch, mouse, keyboard or screen reader."

<objective>
A Dutch-speaking visitor's browser gets the page in Dutch with no flash of English, and any visitor can switch with the `EN · NL` toggle; the choice is remembered in one functional cookie (D-21, D-22, D-23). This plan covers everything rendered by Razor; the next language plan covers the status sentences and the scripts.

Purpose: the language half of the phase's success criterion 5, server side.
Output: `SiteLanguage`, `SiteText`, `LanguageEndpoint`, the toggle, translated page chrome, tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor to `/language/{code}` | Untrusted route value and `sample` query decide a cookie and a redirect |
| Visitor headers to page rendering | `Cookie` and `Accept-Language` choose the language |
| Proxy or shared cache to visitor | A language-varying page could be served to the wrong visitor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04-01 | Tampering (open redirect) | `LanguageEndpoint` redirect | high | mitigate | Redirect target is fixed `/`, plus `?sample={name}` only for a name `SampleCatalog.TryResolve` returns from the allowlist; raw input never reaches `Location`; tests cover a hostile `sample` |
| T-05-04-02 | Tampering (header injection) | cookie value, `Content-Language` | medium | mitigate | Code allowlisted to `en`/`nl`; only the allowlisted lowercase code is written to the cookie and the header |
| T-05-04-03 | Information disclosure | shared caching of the page | low | mitigate | `Vary: Accept-Language, Cookie` and `Content-Language` on the page; no output or response cache exists in the app (research A10); `no-store` on the 303 |
| T-05-04-04 | Tampering (CSRF) | cross-site GET flips language | low | accept | Preference only, `SameSite=Lax`, no state beyond the visitor's own display language; a POST form would need antiforgery and contradicts plain links |
| T-05-04-05 | Denial of service | missing ICU on the host | medium | mitigate | `SiteLanguage.EnsureAvailable()` fails at start with a clear message; the deploy's health check then rolls the release back |
| T-05-04-06 | Information disclosure (privacy) | cookies | low | mitigate | Exactly one functional cookie, `HttpOnly`, no tracking; tests assert the page itself sets no cookie |
</threat_model>
