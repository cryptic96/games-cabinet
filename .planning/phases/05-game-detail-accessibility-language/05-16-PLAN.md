# Plan 05-16: Release v0.6.0 and the owner's check on real devices

## Phase Goal

<objective>
Ship the phase as release v0.6.0 through the established path (pull request, checks, merge, attested tag draft, owner-approved publish, pull-based deploy), then have the owner check the deployed cabinet on desktop and phone, including the Back button on real devices, which no headless browser can prove (D-05, R7; research assumptions A3, A4).

Purpose: the phase is done only when the deployed cabinet does it for the owner's real collection.
Output: v0.6.0 on the container, sanitised evidence in the SUMMARY, the owner's device check.
</objective>
