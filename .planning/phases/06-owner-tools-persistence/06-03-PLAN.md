# Plan 06-03: Verdict kinds and the review sheet's fixes

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Introduce the one mapping from the detector's verdict to the five verdict kinds that the pictures page's tile tags will use, and fold in the review-sheet fixes the owner logged: counts that add up, an unclipped verdict column fixed, a truly read-only snapshot load, and the font, path and surrogate fixes (D-39; the review sheet remains the whole-collection detector tool).

Purpose: the pictures page and the review sheet must never disagree on what a verdict is called, and a read-only tool must never change state.
Output: `ArtVerdictKind`, a read-only snapshot load, the review-sheet fixes with tests, updated `docs/review-sheet.md`.
</objective>
