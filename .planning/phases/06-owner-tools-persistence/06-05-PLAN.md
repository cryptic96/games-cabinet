# Plan 06-05: Plausible cover shapes and an order-independent mapping

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Close the two mapping items of the picture pipeline review the owner folded into this phase (D-38), each with a failing test first: keep an extreme cover from shaping an implausible box, and make the mapping independent of stored order.

Purpose: the owner's picture overrides go through the same mapping and box-shape chain (D-11), so both must be correct before overrides rely on them.
Output: the two fixes with their tests.
</objective>

<interfaces>

- `SnapshotMapper.Explain` groups by `CollectionId` and takes `entry.FirstOrDefault(Kind == Expansion) ?? entry.First()`; `Version` looks entries up with `group.First()`; `CardRecords.BuildContext` keeps the first item per collection id with `TryAdd`.
