# Plan 06-11: Your locations - the owner's own list, edited on a phone

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Build the "Your locations" panel of the Locations page to the UI contract: add, rename in place, reorder with up and down, delete with a confirmation that names the count, Undo on every change, with script enhancing real forms and the shared owner script modules every later owner page uses (LOC-03; D-16, D-17; R6).

Purpose: the owner can set up the storage locations that games are placed into.
Output: location edits, the panel's markup, `owner-shared.js`, `owner-format.js`, `owner-locations.js`, owner stylesheet rules, node and browser tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner browser to Locations handlers | Names, ids, revisions and confirm ids from the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11-01 | Tampering (XSS) | location names in owner pages and dialogs | high | mitigate | Razor encoding, `textContent` only, `dir="auto"`, control and bidi characters refused, CSP; markup-API lint covers `wwwroot/js` |
| T-06-11-02 | Tampering (CSRF) | location posts | high | mitigate | Antiforgery header or field on every post; a bodyless 400 maps to the expired message |
| T-06-11-03 | Tampering | confirm id or location id from the query or form | medium | mitigate | Ids looked up in owner data; unknown ids refused; no path or redirect built from them |
| T-06-11-04 | Repudiation | unnoticed edits by others on the LAN | low | mitigate | Every change logged with its time; Undo; export |
| T-06-11-05 | Denial of service | very many or very long names | low | mitigate | 50 locations, 60 characters, enforced server-side |
</threat_model>
