# Plan 06-04: Details backoff - a game BGG never describes is not asked for every hour

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Close the details-attempt item of the picture pipeline review the owner folded into this phase (D-38), failing test first: record when a game was asked for and came back absent, and back off for a day.

Purpose: keeps the sync polite to the BGG API, and changes the stored collection in a way older releases can still read.
Output: an optional `DetailAttempts` member, the backoff in the planner, stamping in the details step, carry-forward in the runner, tests.
</objective>
