# Plan 06-21: Links that go wrong, and links that stay - every message, the preview's details, Remove link

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Finish the link flow: a specific answer for every problem, staged previews that expire and are capped, the preview's verdict, shape source, 3D note and disclaimer, the stored link that stays a choice, and `Remove link` with Undo (D-09, D-10, D-13; R4; U1).

Purpose: no pasted link leaves the owner guessing, and an owner's link is never lost by accident.
Output: `OwnerStrings.LinkError`, staging tests, preview contents, `PictureEdits.RemoveLink`, browser tests.
</objective>
