<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner-pasted text to the fetcher | Arbitrary strings become outbound fetch targets after policy checks |
| Preview tokens from the client | Tokens address staged bytes |
| Staged bytes to the browser | Processed WebP served from the site's origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-20-01 | Tampering / Information disclosure (SSRF) | CheckLink | high | mitigate | `OwnerLinkFetcher` policy before fetch; only the allowlisted host; caps; shared pacer |
| T-06-20-02 | Tampering (path traversal) | preview tokens | high | mitigate | Regex `^[0-9a-f]{32}$` then dictionary lookup; no filesystem path from request input; 404 otherwise |
| T-06-20-03 | Information disclosure | preview reachable on the public port | high | mitigate | Owner-only marker and port wall; integration test 404 on the public port |
| T-06-20-04 | Tampering (content sniffing) | served preview bytes | medium | mitigate | `image/webp`, `nosniff`, `no-store`; bytes are the processor's own encoding |
| T-06-20-05 | Tampering (CSRF) | CheckLink and UseLink posts | high | mitigate | Antiforgery on every post |
</threat_model>
