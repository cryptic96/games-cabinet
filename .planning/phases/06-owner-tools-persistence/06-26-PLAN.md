# Plan 06-26: Tracer for the owner-address cabinet - the Edit link and the not-placed tag

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Make the cabinet at the owner address a way into the tools: an Edit link on every card that opens that game's single-game view, and a faint corner tag on every unplaced box, both absent from the public address (D-07, D-08; R8; I-B).

Purpose: browsing the cabinet at home turns into editing in one tap, and unplaced games are visible while browsing.
Output: owner-address additions to the cabinet page and card, `owner-cabinet.js`, two bilingual strings, the pencil icon, tests.
</objective>
