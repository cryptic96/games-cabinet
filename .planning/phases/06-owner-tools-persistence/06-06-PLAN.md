# Plan 06-06: The walls hold - bad settings, forged headers, path tricks and forgotten endpoints

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Pin the owner port's two walls against every way they could quietly fail: the full start-up validation matrix, forged forwarding from an untrusted peer, per-request range checks on one connection, path and Host tricks on the public port, endpoints that forgot the owner marker, and owner paths leaking into public content (D-01, D-02, D-28 tests; orchestrator decision 3).

Purpose: one wrong setting or one forgotten marker must not open the owner tools.
Output: the shared forwarded-headers setup, the completed validation, an untrusted-peer test host, a raw-socket helper, and the tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Peer to app | Only the known proxy's forwarded address is believed |
| Client paths and headers to routing | Client-controlled Host and paths reach the public port |
| Configuration to start-up | Ranges and proxy are read once |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06-01 | Spoofing | forged X-Forwarded-For | high | mitigate | Shared `ForwardedHeadersSetup` with `KnownProxies` and `ForwardLimit = 1`; untrusted-peer TestServer test |
| T-06-06-02 | Elevation of privilege | `/0`, mapped or malformed ranges allowing everyone | high | mitigate | Start-up rejects them; unit matrix |
| T-06-06-03 | Elevation of privilege | path or Host tricks reaching owner pages on the public port | high | mitigate | LocalPort-based guards; raw-socket path-trick and spoofed-Host tests; endpoint-coverage test |
| T-06-06-04 | Information disclosure | owner paths in public HTML, scripts or data | medium | mitigate | Leak test over the public page, shared scripts, layout and card data |
| T-06-06-05 | Information disclosure | configured values in errors | medium | mitigate | Messages name the key and index only; test |
| T-06-06-06 | Denial of service | large owner posts | low | mitigate | 64 KB limit test |
</threat_model>
