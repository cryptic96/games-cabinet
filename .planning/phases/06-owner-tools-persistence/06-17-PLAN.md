# Plan 06-17: Every pasted link gets one precise reason, and dead links keep their copy

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Complete the link fetcher's classification and the worker's long-term care: refuse every link that is not a direct picture on the allowlisted host before anything is fetched, map each fetch and decode outcome to one precise reason, extend the downloader and processor additively so the UI-SPEC's messages are possible, and mark links dead, re-check them weekly and re-measure them after an analysis change (D-09, D-10, D-13; orchestrator decision 4).

Purpose: the link UI can say exactly what went wrong, and a stored copy survives a broken link.
Output: additive download and processing seams, the fetcher's classification, the worker's checks, tests.
</objective>
