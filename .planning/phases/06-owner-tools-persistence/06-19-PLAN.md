# Plan 06-19: The single-game view - one game's picture and location in one place

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Give the card's Edit link its target: `/owner/pictures?game={id}` shows that one game's picture row with the shared location picker under it, so "Edit" means edit this game (D-07; U2).

Purpose: from the cabinet at home, one tap leads to everything the owner can change about a game.
Output: the single-game view, the picker's return to the pictures page, tests.
</objective>
