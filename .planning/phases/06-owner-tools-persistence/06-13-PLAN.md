## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Search text and filter query to the page | Free text written back into the page status; a query value chooses the filter |
| Owner browser to the Assign handler | Game id and location id from the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-13-01 | Tampering (XSS) | search query echoed in `No games match "{query}".` | high | mitigate | Written with `textContent`; never markup APIs; CSP |
| T-06-13-02 | Tampering (CSRF) | assign posts, including the `keepalive` flush | high | mitigate | Antiforgery header on every fetch, field on every form |
| T-06-13-03 | Tampering | filter query value | low | mitigate | Only `unplaced` is honoured; anything else ignored |
</threat_model>
