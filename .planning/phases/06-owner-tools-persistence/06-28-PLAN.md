# Plan 06-28: The owner's review round on synthetic data, and the guides

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
Show the owner the finished owner tools locally on synthetic data, the way earlier phases did: the full suite green, the UI-SPEC review matrix as screenshots in a labelled document, the owner's choices (corner tag shape, the Dutch pair, any tuning), applied before release; and the guides updated (CONTEXT "Review flow", UI-SPEC "Review matrix" and "Tuning Register").

Purpose: taste calls are the owner's, made on real renders before anything is released.
Output: the review document and synthetic screenshots in the planning folder, updated guides, the applied choices.
</objective>
