# Plan 06-25: When the stored file can't be read - recovery on every owner page

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 6`): "From the home network or VPN only, the owner can correct box images (and, if BGG cannot supply storage locations, define and assign them), with that data surviving syncs, restarts and releases and being backed up."

<objective>
When the owner-data file on the server is damaged or written by a newer format, show the recovery panel on every owner page with the earlier versions, restore from a file or a version through the same check and confirm, keep the public cabinet working, and never overwrite anything until the owner restores (D-21, D-25; UI-SPEC probe P1).

Purpose: a damaged or too-new file never costs the owner their data, and recovery is two clicks.
Output: the unreadable panel, `Use this version`, restore focus handling, tests.
</objective>
