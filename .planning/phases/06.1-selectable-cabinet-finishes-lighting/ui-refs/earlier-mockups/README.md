# Earlier finish mock-ups (recovered)

These are the furniture mock-ups the owner chose from on 2026-10-05, before classic was built. The files were lost when that session's scratch area was cleared and were rebuilt on 2026-10-13 from the session transcripts. All content is synthetic (invented game titles).

- `screenshots/` holds the screenshots exactly as they were taken then:
  - `set-1-birch-classic-walnut-display.png`: today (then), the planned finish, modern birch plywood, classic, walnut display.
  - `set-2-walnut-oak-library-plywood.png`: walnut done properly, oak on legs, library, plywood with painted backs, each on its own wall.
  - `cubby-depth-flat-shaded-deep.png`: the cubby-depth axis. Its "Flat = like today" label is out of date: today's classic is the Shaded look.
  - close-ups of the library top, the classic base, the walnut display corner and a birch joint.
- `source/set-1` and `source/set-2` hold the mock-up sources replayed from the file writes and edits in the transcripts, with each set's presentation notes. A few small tweaks were applied by shell commands in that session and are **not** in these files; the screenshots show the final state. The sources expect a layout JSON captured from the app at the time, which is not included; the recorded sample layouts in `Cabinet.UnitTests/Layout/Golden/` have a newer layout version.

Use these as the reference for the mock-up round, mapped onto designs and woods as recorded in `06.1-CONTEXT.md`.
