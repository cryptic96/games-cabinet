## Pattern Assignments

### Domain: `CabinetLook.cs` / `CabinetLooks.cs` (replace `Finishes.cs`)

**Analog:** `Cabinet.Domain/Owner/Finishes.cs` (41 lines)

Per-field allow-list, `Normalize` returns value or the default, `SetFinish` returns `OwnerChange.Refused`, `OwnerChange.None` or a new change (lines 9-40):
```csharp
private const string UnknownFinishStatusKey = "unknown-finish";
public static IReadOnlyList<string> Allowed { get; } = [OwnerData.DefaultFinish];
public static string Normalize(string? stored) =>
    stored is not null && Allowed.Contains(stored, StringComparer.Ordinal) ? stored : OwnerData.DefaultFinish;
public static OwnerChange SetFinish(OwnerData data, string? value)
{
    ArgumentNullException.ThrowIfNull(data);
    if (value is null || !Allowed.Contains(value, StringComparer.Ordinal))
        return OwnerChange.Refused(data, UnknownFinishStatusKey);
    if (string.Equals(data.Finish, value, StringComparison.Ordinal))
        return OwnerChange.None;
    return new OwnerChange(data with { Finish = value }, $"Cabinet finish: ...", "finish-set");
}
```
Apply: five strings (design, wood, backs, lights, depth), one allow-list and default each; normalise per field (research Pattern 3, no enums because `StrictEnumConverter` would fail the whole file). Compare all five before returning `OwnerChange.None`. The change-log text is the existing `OwnerChange` second argument. All `///` summaries, no `//`.

**Source:** `Cabinet.Service/Owner/OwnerDataService.cs` (`MutateAsync(revision, edit, ct)` returning `OwnerResult`; `UndoAsync`; `KeepEarlierVersionWhenDue`), `OwnerResponses.For(this, result, PagePath, anchor)`.
