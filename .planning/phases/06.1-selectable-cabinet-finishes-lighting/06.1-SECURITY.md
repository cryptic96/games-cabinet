# Phase 06.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.
> Register built from the `<threat_model>` blocks of all 21 plans (72 IDs; threats repeated across plans share a verdict). Evidence paths are relative to the repository root.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Visitor browser ↔ public port | Public cabinet pages, layout and status endpoints, live channel | Five allow-listed look values, a light-wall flag, collection layout; no owner data |
| Owner browser ↔ owner port | Owner-only Razor Pages and endpoints (Settings look panel, Pictures, Locations, restore) behind the owner-port wall and antiforgery | Owner data writes (look, locations, pictures), restore uploads |
| Service ↔ picture host | Background link worker and the owner's interactive "Check link", separate fetch slots | Image bytes; no credentials, no cookies |
| Service ↔ state directory | Owner-data file, its kept copies, and the upgrade path between formats | Owner data (format 1 → 2) |
| CI ↔ GitHub-hosted runners | Build, test, lint and attested release | Synthetic test data, screenshots, release artifacts |
