## Deviations from Plan

**1. [Rule 3 - Blocking] ImageSharp is not in the solution; SkiaSharp is used instead**
- **Found during:** Task 1
- **Issue:** The plan assumed `SixLabors.ImageSharp` is reachable through `Cabinet.Repository`. The repository references `SkiaSharp` 4.153.1 (and its Linux native assets) instead.
- **Fix:** `PixelComparison` uses `SKBitmap.Decode` and `SKImage` encoding. The types flow transitively to the test project, so no package reference was added and `packages.lock.json` did not change.
- **Files modified:** `Cabinet.BrowserTests/Infrastructure/PixelComparison.cs`
- **Commit:** 8657bb8

**2. [Rule 1 - Bug] Route matching by file-name suffix and by glob would never fire**
- **Found during:** Task 2 (the teeth fact first reported zero differing pixels, which exposed it)
- **Issue:** The host serves fingerprinted names (`cabinet.<hash>.css`), so matching on a path ending in `/css/cabinet.css` never matched; a glob ending in `.css` also fails against URLs with a query. Both made the legacy render silently use the served stylesheets and the identity cases pass vacuously.
- **Fix:** A regex route for any `/css/...css` URL, with the decision made on the file-name stem. The identity cases now also assert that exactly two frozen sheets were served.
- **Commit:** 8657bb8 (stem match and served-sheet counter), 84c4d2d (layer-sheet counter)

**3. [Teeth rule change] The suggested `.section-body` colour shift produces no pixel change**
- **Issue:** `.section-body` is covered by the cubbies, so the plan's example rule changes nothing visible.
- **Fix:** The teeth fact changes the root wood colour variable by one step instead, which the cabinet draws.

**4. Tracer gate handled as the autonomous branch**
- The run is not in auto mode, which would normally return a human-verify checkpoint after the tracer. The tracer's verify is the automated identity test itself; it was re-run end to end (plain and DejaVu fonts) before the expansion task, and a human check of a zero-pixel result adds nothing, so the executor continued. Flagged here for the orchestrator.
