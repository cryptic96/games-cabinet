# Phase 06.1 Plan 07: The owner publishes a look and every cabinet page carries it from the first paint Summary

The cabinet look is now five independent stored strings (design, wood, backs, lights, depth) in owner data schema 2, published from a script-free Settings form and written as five `data-*` attributes on `<html>` of the cabinet page on both ports from the first response; first-format files still load and restore as today's look.

## What was built

- `CabinetLook` (Domain): the record, the five allow-lists in contract order, `Default` (classic, brown, wood, off, shaded), per-field `Normalized()` with ordinal comparison, `IsAllowed`, display names (`On legs`, `Plywood on legs`, `Warm brown`, `Painted backs`, `Always on`, `Evenings only`, ...), `MaxValueLength` (32) and `HasLightWall`.
- `CabinetLooks`: `SetLook` refuses any unknown value with `unknown-look`, returns no change for the stored normalised look, otherwise logs `Cabinet look set to {summary}` with `look-set`; `Summary` builds the contract line.
- `OwnerData.Look` replaces `Finish`; `CurrentSchemaVersion` is 2; `DefaultFinish` is gone.
- Storage: `OwnerDataStore.UpgradeToCurrent` turns a schema-1 document into schema 2 in memory (drops `finish`, adds the five defaults); `Parse` uses it after the header check and normalises the loaded look per field; `OwnerDataExport.Check` uses the same step before deserialising, caps every raw look string at 32 characters, and normalises the accepted look. Required properties list `look` and the five look names. Reads never write.
- Service: `SiteLook.Current` (normalised look, or the default when owner data is unreadable) replaces `SiteFinish`. `_Layout.cshtml` writes the five attributes on `<html>` (read once per request, Razor-encoded) and no body class; `_OwnerLayout.cshtml` drops the finish class, so Pictures, Locations and Settings carry none of the five attributes.
- Settings: `OnPostLookAsync(revision, design, wood, backs, lights, depth)` inside `MutateAsync`; an absent `backs` posts as `wood`. The `#finish` panel is now a plain server-rendered form (radio groups with legends for design, wood, lights, depth; the `backs` checkbox with `role="switch"`; `Use for everyone`) with the stored look, per-field fallbacks included, checked, and a `Visitors see:` line.
- Removed the finish slot: `Finishes`, `SiteFinish`, `owner-finish.js`, its node test and its browser test.
