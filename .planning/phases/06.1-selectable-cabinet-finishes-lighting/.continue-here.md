## Lessons for the remaining plans

- Run full browser suites one at a time on this host; parallel suites exhaust inotify (`DOTNET_USE_POLLING_FILE_WATCHER=1` works around it, but then `TestHostCleanupTests` fails because it counts inotify instances).
- Browser tests that switch looks or take full-page screenshots must fit the viewport to the page first (`FitViewportToPageAsync`), or the cabinet reloads mid-capture.
- The gitleaks `internal-hostname` rule matches text like `name.local ` in comments; the one historical false positive is pinned in `.gitleaksignore`.
- `build/lint.sh`'s secrets step cannot run inside a linked worktree; run it after merge.
- Worktree cleanup refuses branches with deletions; verify the deletions are planned, then merge by hand.
