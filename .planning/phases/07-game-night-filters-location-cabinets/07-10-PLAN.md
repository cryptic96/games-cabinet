# Plan 07-10: Every copy's place and the owner's order reach the page

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan lifts LOC-01 adjacency, empty and ordering (as data on the public card), and the privacy prohibition.

<objective>
Carry the owner's location order and each copy's location id to the page: a `LocationBook` on the collection state, `locationId` on each card, `locations` on the cards document, both folded into the collection version so owner changes reach open pages (LOC-01). Give the samples invented locations with stable ids, and add the shared synthetic fixture the later filter and location tests use. The location select that reads this data lands in plan 07-17; the location cabinets in plan 07-14.

Purpose: every later location feature reads the same data, on the public port, with no extra request.
Output: `LocationBook`, the extended cards document, sample locations, `FilterFixture`, tests.
</objective>
