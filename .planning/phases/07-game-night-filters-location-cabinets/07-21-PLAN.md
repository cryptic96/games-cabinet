# Plan 07-21: Filters last for the tab, and the first frame is already in shadow

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan lifts UI E1 loading and error, E3 loading and error, E4 error, and the cookie and address prohibition.

<objective>
Keep the visitor's filters for the tab (D-17) across reloads, the language switch and live redraws, and make "dimmed in the first frame" true everywhere (D-18 R5): any stored filter makes the page wait for the card data and draw once, dimmed (the owner's Q1). Handle the card data failing (disabled controls, search still works), and keep filters and scroll through a live redraw after an owner change.

Purpose: a visitor who reloads or switches language mid-search keeps their game-night question, and nothing flickers.
Output: `filter-state.js`, the load order in `cabinet.js`, the disabled state, `FilterPersistenceTests`.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-21-01 | Tampering (poisoned storage) | `sessionStorage` and `localStorage` values | medium | mitigate | Field-by-field allow-list parsing; a bad field resets alone; the query is capped and only matched, never written into markup |
| T-07-21-02 | Information disclosure | Filter state in cookies or the address | medium | mitigate | Storage only; no cookie and no address change; browser test asserts the address is unchanged |
| T-07-21-03 | Tampering (integrity) | Cards of another version dimming a new layout | medium | mitigate | `cards.layout` must equal the layout's ETag, one retry on mismatch |
| T-07-21-04 | Denial of service | Storage throwing in private mode | low | mitigate | Every storage call guarded; state kept in memory |
</threat_model>
