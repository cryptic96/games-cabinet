# Plan 07-18: A picture link belongs to one copy

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan lifts no probe edge.

<objective>
Make the owner's picture-link flow per copy (D-31): check a pasted link, preview it, use it, remove it and undo, each naming the copy's collection entry, so each edition can carry its own linked picture. The background link checks follow in plan 07-20.

Purpose: the owner can give one edition a better picture without touching the other.
Output: per-copy `UseLink`, `RemoveLink`, `LinkPreview`, staged links and link handlers; tests.
</objective>
