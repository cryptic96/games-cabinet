# Plan 07-19: A Dutch or other title finds the game too

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan carries the two BGG prohibitions (no visitor-triggered BGG call, no relay).

<objective>
Publish the alternate names the sync keeps (plan 07-04) as a small, lazily fetched names index and let the search match them (D-14, FILT-01), so a Dutch visitor typing a Dutch edition's title finds the game, without the site ever asking BGG on a visitor's behalf and without relaying BGG data.

Purpose: visitors search in their own language.
Output: `SearchNames`, `/cabinet/search-names` with its cache, the lazy index in the page, sample alternate names, tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public endpoint to any client | `/cabinet/search-names` is readable by anyone who can reach the site |
| Visitor typing to the server | Must not exist: matching stays in the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-19-01 | Information disclosure (licence) | Names index as a relay of BGG data | high | mitigate | Owned games only, cleaned alternate names only, no other details fields, no CORS headers, undocumented; `SearchNamesTests` and `SearchNamesEndpointTests` assert the shape |
| T-07-19-02 | Denial of service | Unbounded names payload | medium | mitigate | Parse-time caps (plan 07-04), lazy fetch on first use only, content-hash ETag so repeats are 304s |
| T-07-19-03 | Denial of service (host and BGG) | Per-keystroke server work or BGG calls | high | mitigate | Matching runs in the browser; the endpoint is a cached document per collection version; the browser test asserts only loopback requests while typing |
| T-07-19-04 | Tampering (script injection) | Alternate names matched in the page | medium | mitigate | `CleanTitle` removes control and bidi characters; names are never written into markup (matching only); `textContent` everywhere |
</threat_model>
