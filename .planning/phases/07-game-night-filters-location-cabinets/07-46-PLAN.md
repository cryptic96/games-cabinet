# Plan 07-46: Release v0.10.0 (provisional), part one - pull request, the owner's merge and tag, and a verified draft

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: the established release path of plans 07-32 and 07-33 (CONTEXT "Review flow": a release the owner approves after the draft check), for the filter rail and panel. This plan lifts no amendment item; it ships them.

<objective>
Take the rework to a verified release draft through the established path: pull request, checks watched by the orchestrator, the owner's explicit approval to merge and tag (with the version confirmed), then the attested tag draft verified on the workstation, and the owner told plainly that the draft is verified. Publishing (the deploy approval) and the container check follow in plan 07-47. The public route keeps its LAN/VPN allow-list.

Purpose: the rail and panel are merged and built as an attested draft that the owner can approve with confidence.
Output: the merged pull request, the approved tag, a verified draft, sanitised evidence in the SUMMARY.
</objective>

3. `gh release list --limit 1 --json tagName,isDraft` shows `v0.9.0`, published. Create an annotated tag with the approved version on `origin/main` with the repository's noreply tagger identity and a plain message; `build/validate-release-tag.sh` accepts it; push it.
4. About every three minutes, at most ten times, run `gh release view <tag> --json isDraft,assets --jq '"\(.isDraft) \(.assets | length)"'` until it prints `true 3`. 6. If the release was already published, run `build/verify-published-release.sh <tag>` instead and record every result line's outcome; never publish anything yourself.
7. Tell the owner plainly: the draft is verified (checksum, attestation, manifest) and nothing is published yet; the deploy approval follows in the next step (or, if it was already published, that it was verified as published).
