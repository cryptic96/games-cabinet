# Plan 07-08: The Locations page shows and places every copy

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan lifts no probe edge. Folded todo: owner pages collapse owned versions of one game (Locations page half).

<objective>
Put the per-copy owner data of plan 07-03 on the Locations page (D-31): one row and one picker per copy, the copy tag, the picker's per-copy accessible name, and an assign handler that takes the copy's collection id and refuses a foreign one. Then move every remaining caller off the overlay's game-keyed location accessors and delete them, so nothing can silently pass a game id where a copy is meant. Edition names, bulk moves, counts and search per copy follow in plan 07-12; the Pictures page in plan 07-16.

Purpose: the owner places each copy of a game where it really stands.
Output: per-copy rows, pickers and posts; the copy strings; the entry-only overlay; integration and browser tests.
</objective>
