# Plan 07-13: A picture chosen for one copy is drawn on that copy's box

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: no SPEC; spec-less probe fallback ran (see plan 07-01). This plan lifts no probe edge.

<objective>
Make the picture half of D-31 per copy below the owner pages: the overlay resolves each copy's picture choice, the mapper picks each copy's art from it and includes it in the collection version, and the picture edits gain per-copy forms that split a game-wide entry first, so two editions of one game can show their own boxes (LOC-05 draws boxes by collection entry). The Pictures page moves to per-copy rows in plan 07-16; the picture-link flow in plans 07-18 and 07-20.

Purpose: a game owned in two editions can look like two different boxes, as it does on the real shelf.
Output: `EntryPictureOverride`, the entry-keyed mapper, per-copy `PictureEdits.Choose` and `LooksRight`, tests.
</objective>
