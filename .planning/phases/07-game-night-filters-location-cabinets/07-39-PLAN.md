# Plan 07-39: The panel is remembered per device, the first frame is already right, and nothing is open on a first visit

## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 7`): "A visitor can narrow the cabinet to tonight's game by dimming everything else, and can switch between one big cabinet and one cabinet per storage location."

Coverage note: amendment AM-8 (the remembered state, the head script, never a fly-over at load, storage throwing, independence), AM-3 ("Reserving the column at the first paint"), AM-11 (per-tab filter memory and per-device view memory), AM-14 (E11 empty and loading) and AM-16 (the default-folded row, the remembered-state row, the `node --test` panel key row). It carries the owner's firm requirement: the filter options are not visible by default when someone views the cabinets.

<objective>
Remember per device whether the visitor left the panel open, read it before the first paint through a tiny external head script so a returning visitor never sees the panel jump open, never open a fly-over at load, keep the stored value honest, and collapse the dock on pages that have no cabinet. Prove the owner's requirement at every width.

Purpose: the cabinet stays the first impression for everyone, and the owner's own choice sticks on the owner's own devices.
Output: `filter-dock-head.js`, panel-key helpers in `filter-state.js`, the dock's reads and writes, empty-page handling, `FilterDockMemoryTests`.
</objective>
