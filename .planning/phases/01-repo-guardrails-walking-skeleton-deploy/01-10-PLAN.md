## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 1`): "A public repository with enforced guardrails and a proven release pipeline, so a hello page travels from semver tag to approved release to running LXC (and back via rollback) before any feature depends on it."

<objective>
Port the reference project's root installer and libraries with everything database-, metrics- and mail-related removed, and close its two behavioural gaps: remember a rolled-back version and skip it until something newer is published (D-12), and treat "no release yet" and rate limiting as quiet outcomes while logging the remaining rate limit (D-14). Health acceptance becomes "loopback `/health` JSON is Healthy and reports the expected version".

Purpose: this is the server half of the walking skeleton and the mechanism the rollback rehearsal (D-11) exercises; it is proven here end to end against real packaged releases before any server exists.
Output: `deploy/bin/cabinet-deploy`, `deploy/lib/{common,deploy}.sh`, `deploy/deploy.conf.example`, logic, end-to-end and tamper tests, `build/verify-published-release.sh`, `docs/deploy.md`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub releases (public download) -> root installer | Untrusted bytes until checksum and attestation pass |
| Sigstore public-good instance -> installer | Trust root fetched during verification |
