## Conventions for every file this plan writes

- No planning references outside `.planning/` (requirement keys, decision IDs, phase or plan numbers, planning document names) in scripts, configs, docs, comments or messages. Every lint pattern and self-test fixture is written so its own source cannot match it (grouped alternations with the shared suffix outside the group, one bracketed letter such as `\.plannin[g]/`, fixtures assembled with `printf` from fragments).
- Shell: `set -euo pipefail`, quote every expansion (the checkout path contains a space), arrays for argument lists, `#` comments allowed. Under `pipefail` never pipe into `grep -q`; capture then match.
- Placeholders only: `example.com`, RFC 5737 addresses; no real values in rules, allowlists or fixtures.
- Container images keep the reference's tag-plus-digest pins.
