## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 1`): "A public repository with enforced guardrails and a proven release pipeline, so a hello page travels from semver tag to approved release to running LXC (and back via rollback) before any feature depends on it."

<objective>
Turn the hello-page app into the release artefact the pipeline attests and the server installs: a packaging script whose zip runs from a symlinked release directory exactly as the server will run it, and an `image-smoke` subcommand that proves the SkiaSharp imaging stack (D-17) inside any host the release lands on.

Purpose: the release workflow builds this zip, the installer's end-to-end test installs it, and the container's selfcheck runs its image smoke.
Output: `Cabinet.slnx`, the `Cabinet.Repository` and `Cabinet.UnitTests` projects, `build/package-release.sh`, `build/tests/package-release-e2e-test.sh`.
</objective>
