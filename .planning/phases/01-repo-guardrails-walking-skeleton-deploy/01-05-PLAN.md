<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pull request authors -> CI | Untrusted code runs on GitHub-hosted runners with a read-only token |
| tag push -> release build | Tags are admin-only by ruleset; the build attests what it produced |
| draft -> published release | The deploy environment reviewer is the human gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-051 | Elevation of privilege | release.yml publish | high | mitigate | publish job bound to environment deploy with a required reviewer; environment existence and reviewer read back before the first tag (go-live ordering) |
| T-01-052 | Tampering | workflow expressions | high | mitigate | github.ref_name passed via env only and validated by strict semver before use; zizmor and actionlint gate every PR |
| T-01-053 | Tampering | third-party actions | high | mitigate | Full-SHA pins with version comments; zizmor hash-pin policy; repository SHA-pinning setting checked by check-github-settings.sh |
| T-01-054 | Tampering | release artefact | high | mitigate | Build provenance attestation; publish job re-verifies checksum and attestation with signer workflow, source ref and --deny-self-hosted-runners |
| T-01-055 | Elevation of privilege | default GITHUB_TOKEN | medium | mitigate | permissions {} at top level, per-job minimum grants, persist-credentials false, default workflow permission read |
| T-01-056 | Repudiation | immutable releases | medium | mitigate | Releases are drafts until approval and immutable after; docs require editing notes before approval |
| T-01-057 | Elevation of privilege | settings checker | low | mitigate | Read-only GET calls only; test asserts no mutating method appears in the script |
</threat_model>
