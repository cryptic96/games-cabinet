## Conventions

- Pull request titles and bodies, release notes and repository descriptions are public: no planning references and no personal data. End the pull request body with the attribution line required by this repository's agent instructions.
- Nothing private is written to a committed file or SUMMARY: refer to the owner by the public handle only.
- Pushes go to `main` exactly once, before any ruleset exists (D-16); after that `main` changes only through pull requests.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workstation -> public GitHub | History and licence become public and permanent |
| GitHub web merge -> history | GitHub writes the merge commit with the account's profile identity |
| repository settings -> release path | Rulesets and the deploy environment are the controls every later release depends on |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-121 | Information disclosure | first push | high | mitigate | Full local gate and build/scan-history.sh immediately before push; fresh public clone scanned again after |
| T-01-122 | Information disclosure | merge-commit identity | high | mitigate | Owner profile name and email privacy set before approval; origin/main identities verified before any tag; escalation path if wrong |
| T-01-123 | Elevation of privilege | deploy environment auto-created unprotected | high | mitigate | Environment, reviewer and tag policy created and read back before any tag is pushed |
| T-01-124 | Tampering | main branch | high | mitigate | Ruleset: pull request required, required checks by exact name and app id, no force-push, no deletion, no bypass actors |
| T-01-125 | Tampering | release tags | high | mitigate | Admin-only v* tag ruleset; immutable releases enabled before the first publish |
| T-01-126 | Elevation of privilege | fork pull requests and default token | medium | mitigate | Approval for all outside contributors; read-only default workflow token; SHA pinning required |
| T-01-127 | Repudiation | settings drift | low | mitigate | build/check-github-settings.sh is a repeatable read-only proof, re-run in the final gate |
</threat_model>
