## Phase Goal

ROADMAP goal (not yet in user-story form; flagged to the orchestrator, run `/gsd mvp-phase 1` to restate it as a story): "A public repository with enforced guardrails and a proven release pipeline, so a hello page travels from semver tag to approved release to running LXC (and back via rollback) before any feature depends on it."

This plan is the first gate of that path: nothing may be pushed until the local history is free of personal data.

<objective>
Scrub the homelab specifics out of every tracked planning and Claude instruction file and rewrite all existing local history in place, keeping commits, dates and messages (D-04, D-05), then prove the result with a reusable full-history scan.

Purpose: the repository goes public later in this phase and a pushed history is effectively permanent. Doing this first, alone in its wave, means every later commit is made on top of clean history and no parallel executor is orphaned by the rewrite.
Output: `build/scan-history.sh` (committed, generic), rewritten local history, a mirror backup outside the repository, an expressions file outside the repository.
</objective>

## Conventions for every file this plan writes

- No planning references outside `.planning/` (requirement keys, decision IDs, phase or plan numbers, planning document names) in `build/scan-history.sh`, its messages or comments. IDs in this plan are traceability for the planner only.
- Shell scripts: `set -euo pipefail`, quote every expansion (this checkout's directory name contains a space), build argument lists as arrays, `#` comments allowed.
- Never write absolute local paths, hostnames, addresses, denylist values or personal names into any committed file or SUMMARY. Refer to private files only by their `${XDG_CONFIG_HOME:-$HOME/.config}`-style expression, written literally.
- Grep patterns for absolute home or mount paths are written with one bracketed letter (for example `/hom[e]/`, `/mn[t]/`) so the script never matches its own source.

1. Create `build/scan-history.sh` (executable, bash, `set -euo pipefail`). Options: `--repo PATH` (default: the repository containing the script; bare mirrors must work) and `--denylist PATH` (default `${CABINET_DENYLIST_FILE:-${XDG_CONFIG_HOME:-$HOME/.config}/games-cabinet/denylist.txt}`).    - `denylist-trees`: for each denylist line N (comments and blanks stripped), run one case-insensitive fixed-string `git grep -I -l` across every commit from `git rev-list --all`; report `commit:path denylist match #N`, never the matched text.
   - `denylist-messages`: the same patterns over `git log --all --format=%B`, reporting commit and pattern number only.
   - `denylist-identities`: the same patterns over author and committer names and emails of every commit.
   - `noreply-identities`: every author and committer email over `--all` must end in `@users.noreply.github.com` or equal the GitHub web-flow committer address `noreply@github.com`.
   - `absolute-paths`: `git grep -I -E` over all commits for absolute home, mount and macOS user paths followed by a further path segment (bracketed-letter patterns), reporting commit:path:line.
   - `gitleaks-all-refs`: run the pinned gitleaks container image (digest copied from `ing-dashboard:build/lint/compose.yaml`) in git mode with `--log-opts=--all --redact`, using the repository's `.gitleaks.toml` when present and gitleaks defaults otherwise. If the image refuses a bare repository, scan a temporary non-bare clone of it instead.
2. Run `build/scan-history.sh` against the real repository and record the per-check FAIL counts (counts only) as the baseline.
3. Build the scrub inventory: every location from the research scrub inventory plus every location the baseline reported, plus a read-through of all tracked text files (including `01-DISCUSSION-LOG.md` and `01-RESEARCH.md`, which quotes some of the terms it inventories) for homelab specifics the denylist may not list. Sibling-relative references to the reference checkout in `01-CONTEXT.md` become `ing-dashboard:<path>` (D-04).
4. Write the expressions file `${XDG_CONFIG_HOME:-$HOME/.config}/games-cabinet/history-rewrite.txt` (chmod 600, outside the repository): `regex:(?m)^<distinctive line prefix>.*$==><generic line>` entries keyed on each affected line's prefix so every historical version of that line is covered, and `literal:` entries for single terms. 7. Commit `build/scan-history.sh` on the milestone branch (message without personal data).

## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-011 | Information disclosure | git history (all refs) | high | mitigate | filter-repo replace-text over every commit, then build/scan-history.sh over all refs: denylist in trees, messages and identities, absolute-path heuristics, gitleaks with --log-opts=--all |
| T-01-012 | Information disclosure | denylist, expressions file, SUMMARY | high | mitigate | Both files live under the XDG config dir with mode 600, are never added to git; the scan prints pattern numbers, never values; SUMMARY refers to private files by literal variable expressions |
| T-01-013 | Tampering | rewritten history | medium | mitigate | Dry run in a throwaway mirror first, owner approval checkpoint, before/after commit-count and date-and-subject equality, mirror backup without a remote |
| T-01-014 | Spoofing | commit identities | medium | mitigate | noreply-identities check fails on any author or committer email that is not a GitHub noreply address |
| T-01-015 | Information disclosure | backup mirror | medium | mitigate | Stored under XDG state outside synced folders, remote removed, deleted after the pushed history scans clean in the go-live step |
