## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 1`): "A public repository with enforced guardrails and a proven release pipeline, so a hello page travels from semver tag to approved release to running LXC (and back via rollback) before any feature depends on it."

<objective>
Pin the application contract the installer and visitors rely on with fast tests that CI runs on every pull request: ops-only health JSON with version, a public 404 for `/health`, health that is healthy with nothing on disk, the version-bearing hello page and its stylesheet, BuildInfo parsing, the loopback-only ops listener rule and committed configuration free of secrets. No test asserts the committed ops port, because the rollback rehearsal changes it on purpose (D-11).

Purpose: the `build-test` required check exercises these tests; a change that exposes health publicly or breaks the version contract fails before it can be released.
Output: `Cabinet.IntegrationTests` project, the contract unit tests in `Cabinet.UnitTests`, both in `Cabinet.slnx`.
</objective>
