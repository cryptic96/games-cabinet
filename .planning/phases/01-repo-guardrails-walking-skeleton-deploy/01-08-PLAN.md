<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| systemd timer -> root installer | The poll unit runs as root inside a narrowed sandbox |
| root selfcheck -> deployed binary | The image smoke executes release code as an unprivileged user in a transient sandbox |
| admin workstation -> container | SSH is the only admin path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-081 | Elevation of privilege | cabinet-deploy-poll.service | high | mitigate | ProtectSystem=strict with ReadWritePaths limited to /opt/cabinet and /var/lib/cabinet-deploy, NoNewPrivileges, kernel and namespace restrictions; asserted by sandboxing-test.sh |
| T-01-082 | Elevation of privilege | cabinet.service | high | mitigate | Unprivileged user, empty capability set, strict system protection, StateDirectory as the only writable path |
| T-01-083 | Elevation of privilege | image smoke run by root selfcheck | medium | mitigate | systemd-run as cabinet with the full sandbox property list and AF_UNIX only; asserted by sandboxing-test.sh |
| T-01-084 | Spoofing | SSH | high | mitigate | Selfcheck fails unless sshd reports password and keyboard-interactive authentication off; firewall limits sources |
| T-01-085 | Elevation of privilege | GitHub-side code on the host | high | mitigate | Selfcheck fails on any GitHub credential, gh hosts file, runner unit, runner process or runner directory |
| T-01-086 | Information disclosure | docs | medium | mitigate | Placeholders only; lint secrets check; real values only in server-side files |
| T-01-087 | Repudiation | false PASS under pipefail | medium | mitigate | Every check captures output before matching, avoiding early-closed pipes |
</threat_model>
