## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 3`): "The owner's real BGG owned collection appears automatically in the deployed cabinet, kept fresh by a polite hourly sync and a guarded 'sync now', and the site keeps working when BGG does not."

<objective>
The tracer of the sync: pressing "sync now" makes the server fetch the owned collection from BGG (two paced, authenticated collection calls), store it atomically on disk, and show it in the cabinet; a restart shows the same cabinet (SYNC-01, D-01). Later plans add the hourly timer and cooldown, faithful mapping and secret hardening, failure handling and the page controls on top of this path without changing its shape.

Purpose: prove the whole path from button to BGG to disk to cabinet before expanding any layer.
Output: Domain snapshot types and mapper, BGG transport, pacer, client and parser, atomic snapshot store, sync coordinator, worker, runner and endpoint, storage location, tests, env example and an operations guide.
</objective>
