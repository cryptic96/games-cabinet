## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 3`): "The owner's real BGG owned collection appears automatically in the deployed cabinet, kept fresh by a polite hourly sync and a guarded 'sync now', and the site keeps working when BGG does not."

<objective>
Prepare the layout data and renderer for real games: each drawn box knows which collection entry it is (so two copies are two distinct boxes and later features key on the entry), and an expansion whose base game is not known reads "Expansion" instead of naming a base game (D-15, D-19). The layout version moves to 9 because the JSON changes.

Purpose: real collections contain duplicate copies and, until base games are paired in the next phase, expansions without a known base; both must render correctly the moment the first real sync lands.
Output: `Placement.EntryId` and `Placement.IsExpansion`, re-recorded goldens, renderer and strings changes, tests.
</objective>
