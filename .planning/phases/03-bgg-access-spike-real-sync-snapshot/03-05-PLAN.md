## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 3`): "The owner's real BGG owned collection appears automatically in the deployed cabinet, kept fresh by a polite hourly sync and a guarded 'sync now', and the site keeps working when BGG does not."

<objective>
Switch the page and the layout endpoint from invented samples to the synced collection: before the first sync, visitors see the intentional "cabinet is being filled" state over the bare cabinet (D-16, SYNC-05); the invented collections stay only in local development (D-17).

Purpose: the deployed site must only ever show the owner's real collection; the sync built next fills the same store this plan reads.
Output: `CollectionStore`/`CollectionState`, the synced path of the layout endpoint and cache, the being-filled state, the development-only switcher, updated tests and docs.
</objective>
