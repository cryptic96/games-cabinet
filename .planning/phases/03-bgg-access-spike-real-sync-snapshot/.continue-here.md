## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Uncommitted drafts in a worktree | A plan task that must leave a file uncommitted (03-02's draft outcome) loses it when the executor's worktree is removed | advisory | Dispatch such plans without `isolation="worktree"`, sequentially on the main tree |
| Parallel worktree dispatch in one message | Several `Agent(isolation="worktree")` calls in one message race on `.git/config.lock` | advisory | One Agent dispatch per message, `run_in_background: true` |
| Reading the server env file | The auto-mode classifier denies Claude reading `/etc/cabinet/cabinet.env`, even key names only | advisory | Give the owner the exact command; the owner runs it and pastes the value-free output |
| Rebuilding a failed WebApplicationFactory host | The deferred host builder's shared start signal stays faulted after a failed start, so rebuilding on the same builder never recovers | advisory | Retry through `WebApplicationFactory.Server` (already implemented in `CabinetWebApplicationFactory`) |
