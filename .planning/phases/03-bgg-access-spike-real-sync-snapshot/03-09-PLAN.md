## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 3`): "The owner's real BGG owned collection appears automatically in the deployed cabinet, kept fresh by a polite hourly sync and a guarded 'sync now', and the site keeps working when BGG does not."

<objective>
Make the synced collection faithful and the credentials provably server-side: every owned copy, expansion, interim box size and (when BGG exposes it) location reaches the snapshot as BGG lists it (D-04, D-14, D-15, D-19), and the token and username never leave the server (SEC-05).

Purpose: the cabinet must show exactly what the owner owns, and the public repository and site must never expose the BGG credentials.
Output: parser and client fidelity, the box mapper, settings hardening, a start-up configuration report, leak and routing tests, and the local development guide for credentials.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> BGG API | The only place the token travels |
| BGG answer -> snapshot | Untrusted titles, dimensions and private locations |
| app -> logs and responses | Must never carry credentials |
| visitor -> sync now | Request content must never reach BGG |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-34 | Information disclosure | token on another host or after a redirect | high | mitigate | Host-pinned auth handler with unit tests for look-alike hosts; no redirect following (unit test plus a scripted 301 integration test) |
| T-03-35 | Information disclosure | credentials in logs or responses | high | mitigate | Sentinel-credential tests over captured logs (with committed filters) and every public response of this plan |

| T-03-39 | Denial of service | missing credentials after a release | medium | mitigate | Not a start-up error: one warning, being-filled page, healthy `/health`, NotConfigured without requests (test), so the installer never rolls back for it |
