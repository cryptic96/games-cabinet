## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 4`): "Every game in the real cabinet shows its real box art (or a spine coloured from that art) at true proportions, with complete BGG details behind it, all served from the site itself."

<objective>
The phase tracer: real box art travels from the collection answer, through a polite token-less download, a bounded resize to WebP and a content-hashed cache under the state directory, into the layout JSON and onto face-out covers that the browser loads from the site's own origin. Later plans add the second candidate and the detector, art colours, true box shapes and enrichment on top of this path without changing its architecture.

Purpose: proves every layer this phase touches (parser, snapshot, image pipeline, sync run, static serving, mapper, engine, renderer) with one real picture before anything is built out (D-06, D-17).
Output: schema-2 snapshot with image records, the image pipeline, `/art` serving, art covers in the renderer, tests and a docs section.
</objective>
