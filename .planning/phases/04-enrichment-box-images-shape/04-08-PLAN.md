## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 4`): "Every game in the real cabinet shows its real box art (or a spine coloured from that art) at true proportions, with complete BGG details behind it, all served from the site itself."

<objective>
Wire the two candidates, the detector and the art colours into the sync and the cabinet: download and analyse both pictures of every game, store the raw facts, choose the picture at read time from settings (D-01 to D-03), and colour every box of a game from its chosen picture with a legible title (D-10 to D-12), filling the bars around fitted art with the picture's own edge colours (D-06).

Purpose: IMG-01 and CAB-03 end to end, on the facts the art check measured; tuning thresholds later is a settings change and a restart.
Output: extended image records, `ArtRules` and `Art:*` settings, the read-time chooser in the mapper, colours on placements, renderer support, tests and docs.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored records -> layout JSON | Colours and edges from disk become CSS values in the page |
| image bytes -> analysis | Untrusted pixels drive stored facts |
| settings -> mapping | Operator-provided thresholds change the cabinet |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-30 | Tampering | colour and edge values reaching CSS | medium | mitigate | Server validates with `SpineColour.IsValidPair` and `RgbColour.TryParseHex`; the renderer validates again with a strict `#rrggbb` pattern before `style.setProperty`; invalid values fall back to the palette |
| T-04-31 | Denial of service | two downloads per game | medium | mitigate | Each distinct URL once, existing per-run cap and deadline, own image pacer; a first large sync spreads over several runs |
| T-04-32 | Tampering | settings typo | low | mitigate | `ArtSettings` validated at startup with messages naming the key; inconsistent thresholds refused |
| T-04-33 | Information disclosure | layout JSON | low | mitigate | Only colours, same-origin paths and pixel sizes are added; no URL of BGG or its image host appears (integration assertion) |
</threat_model>
