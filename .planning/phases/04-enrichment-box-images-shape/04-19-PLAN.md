## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 4`): "Every game in the real cabinet shows its real box art (or a spine coloured from that art) at true proportions, with complete BGG details behind it, all served from the site itself."

<objective>
Fix the flat-versus-3D detector again, this time from the real failures of the second server review round (owner decision after round 2, `.continue-here.md`). Plan 17's synthetic fixtures did not match how the real pictures fail, so this plan measures the owner-approved local copies of the stored 480 px pictures first, at several sizes and against the owner-approved stored server features, derives the real failure shapes, mirrors each shape in a synthetic fixture that fails before the fix, fixes the analysis, and confirms the fix on the local pictures again. Rows are named by review-sheet row number only.

Round-2 state (the "before" the harness must reproduce) and the required "after" (A is the owned version's picture, B the main picture):

| Row | Picture | Round 2 | Required after |
|---|---|---|---|
| 8, 13 | A (a box photo) | flat | 3D shot |
| 28, 42 | A (a box photo) | flat | 3D shot |
| 1, 4, 34 | A (a flat cover) | 3D shot | flat |
| 25 | A (a flat cover, landscape) | 3D shot | flat or unsure |
| 8, 15 | B (a flat cover) | not flat | flat |
| 2, 3, 9, 14, 45, 46, 49, 50, 51 | both | as in round 2 | unchanged (controls) |
| 13, 42 | B | as in round 2 | unchanged |

Expected pick changes: rows 8, 13 and 15 pick their flat main picture. Row 42 may pick its main picture; the owner wants the owned edition there, accepts the detector's switch for now, and row 42 joins the override candidates. Rows 8, 13, 15, 42 and 44 (a main picture of another edition) are recorded as candidates for the owner image overrides in a later phase (D-05), by row number only.

Purpose: success criteria 3 and 4 (image choice checked on the owner's editions; true proportions) still fail on these rows; review round 3 (plan 15) judges the result after release v0.5.0 (plan 23).
Output: synthetic fixtures for each measured failure shape plus guards, root-caused backdrop rules that hold at every size checked, an optional cut-out feature, analysis version 3, a wrapped rules line on the review sheet, updated operator docs, an overrides-candidates todo.
</objective>
