## Phase Goal

ROADMAP goal (not yet in user-story form; flagged, see `/gsd mvp-phase 4`): "Every game in the real cabinet shows its real box art (or a spine coloured from that art) at true proportions, with complete BGG details behind it, all served from the site itself."

<objective>
Build the owner's review instrument (D-04): a server-run operator mode of the service that draws a contact sheet of every game's candidates, verdict, choice, resulting box, spine colour and size source from the stored collection and art cache, using the exact settings the deployed cabinet uses. Ship the font it needs through provisioning.

Purpose: success criterion 3 is "checked against the owner's real Dutch editions"; that check happens on this sheet, on the server, without any of the owner's data entering the repository.
Output: `review-sheet` command, model, drawing, font package line, tests and an operator guide.
</objective>

| operator shell -> service binary | An operator mode runs with the service user's rights |
| sheet pages -> workstation | Private titles and pictures leave the server |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-40 | Information disclosure | sheet pages and console output | high | mitigate | Console prints counts only (tested); pages written only to the given directory; the guide says never commit or publish and delete after delivery; the pre-commit personal-data hook stays active |
| T-04-41 | Elevation of privilege | an operator mode reachable from the web | medium | mitigate | Dispatched from `args` before the web host exists; no route is mapped (acceptance grep); runs only by an operator with server access |
| T-04-42 | Tampering | font file path | low | accept | The font path comes from the operator's own command line or fixed system paths on the server |
