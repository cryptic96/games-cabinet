# Third-party image: "Powered by BGG" logo

`powered-by-bgg.svg` in this directory is BoardGameGeek's official "Powered by BGG" logo, the reversed RGB SVG variant, taken from the official logo pack that BoardGameGeek links from its XML API terms of use. It is shown, linked back to BoardGameGeek, in the footer of every public page as the attribution those terms ask for.

| Source | BoardGameGeek's official logo pack, linked from BoardGameGeek's XML API terms of use (the exact page address is not recorded here) |

| Rights holder | BoardGameGeek |
| Terms | Used under BoardGameGeek's XML API terms of use, which require this logo, linked back to BoardGameGeek, on public-facing uses of its data |

The file is copied unchanged: it is not recoloured, resized, re-encoded or edited here. A unit test pins the SHA-256 above, so any change to the file fails the build. The logo is not covered by this repository's licence.

To replace it, take the new file from BoardGameGeek's official logo pack, update the hash above and in the unit test, and keep it unmodified.
